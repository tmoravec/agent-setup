### Code comments
Avoid writing any comments unless absolutely necessary. Code should be
sufficiently readable on its own. In the rare cases you write a comment,
focus on the WHY, not the WHAT or HOW.

### Git
Never use Git for mutations, including commits or applying patches - and you
don't have the GPG key anyway and commits must be signed by policy.
The user commits by hand in a different environment.
Read-only Git operations are allowed.
